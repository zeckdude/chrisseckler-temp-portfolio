## Superpower: Design Systems & Component Libraries

This is where Chris creates disproportionate leverage for a team. When he joins a project or team:

1. **Partners with design** to build a design system (or establish one if it doesn't exist).
2. **Creates a component library** that maps to that design system — modular, extensible, well-written.
3. **Documents in Storybook** so engineers see usage examples, props, and patterns in real time.
4. **Writes supporting docs** for the team on how to use and extend the library.
5. **Sets up a process** for how the team communicates about changes and additions going forward.

**Result:** A system that scales. New engineers ramp faster. Changes happen in one place. Quality and consistency go up. The team moves quicker — across the board, not just for Chris.

## Philosophy: User-First + Critical Thinking

Many engineers execute what's in front of them. Chris thinks bigger.

**He asks:** Does this actually solve the user's problem? Are we missing something? Does this align with the business goals? What tradeoffs are we making?

**He pushes back** — respectfully and constructively, but he speaks up when he thinks something won't work or could be better.

**He marries UX and business.** Both matter. He finds the path that honors both.
